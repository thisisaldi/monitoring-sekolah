{% comment %} FormField composed component: Label + widget + help text + error, for a single Django BoundField. Use when a form is laid out field-by-field (instead of {{ form.as_p }}) to get the section-50 "one coherent form" layout. The widget itself (Input/Textarea/Select) still gets its base visual treatment from the global `@layer base` rules in tailwind/input.css -- this component only adds the label/help/error scaffolding around it.
